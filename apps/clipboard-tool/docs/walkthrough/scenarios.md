## 素材清单

### S-01 | L1 单链直通 | 深度
- 操作链:新建用户「测试」→ 进主页面 → 顶部粘贴框 Ctrl+V 粘贴「hello world」→ 点存入 → 列表出现文本卡片 → 单击卡片 → 提示「已复制」
- 预期:全链路通,复制计数 +1
- 覆盖 C-ID:C-03, D-01, D-02, F-03, F-04, E-01
- 结果:**通**。`openPasteModal` → `savePasteContent`(L1111)→ POST /api/clips → `refreshList`(L1092);单击 `handleCardClick`(L751)→ `copyText` + POST /copy + 本地计数 L769-774

### S-02 | L4 状态机长链(删除→墓碑) | 深度 ★缠绕点1
- 操作链:删除一条文本条目 → 确认弹窗点「删除」→ flash「已删除」→ 列表刷新条目消失 → 检查服务端 `users/<uid>.tombstones.json` 出现 `{id, deletedAt}` → 再次删除另一条 → 墓碑文件追加
- 预期:条目删净;墓碑如实记录(供 WebDAV 传播删除)
- 覆盖 C-ID:F-13, D-01, D-06, D-15
- 结果:**通(但见 P-102)**。`makeDeleteBtn`(L682)→ DELETE /api/clips/:id → routes/clips.js L43-48 → `deleteClip`(clips.js L396)→ `recordTombstone`(L77)→ 写 tombstones.json。**副作用:未配置 WebDAV 的用户也每次写墓碑文件**(缠绕点 1 真实后果,见报告 P-102)

### S-03 | L9 故障注入(删除时断网) | 深度 ★真缺陷验证
- 操作链:删除条目 → 确认 → 网络断开/服务 500 → 观察提示
- 预期:errToast「请求失败」,**不应**提示「已删除」
- 覆盖 C-ID:F-13, F-11, F-12
- 结果:**🔴 不通(P-101)**。`makeDeleteBtn`(L683)`.catch(e2 => errToast(e2.message))` 吞掉异常后,**无条件执行** `flash("已删除")` + `refreshList()`(L684-685)——删除失败也提示成功。对比:删用户(L263)/删标签(L578)/置顶(L648)/JSON 覆盖(L995)全部 `if (r)` 检查,唯此处遗漏

### S-04 | L4 搜索双实现一致性 | 深度 ★缠绕点8
- 操作链:存「身份证明」→ 搜索框输入「sf」→ 前端命中;刷新页面后地址栏带 `?q=sf`(模拟)→ 后端查询 → 观察是否命中
- 预期:两种入口语义一致
- 覆盖 C-ID:F-01, F-02, D-03
- 结果:**通但有语义差(P-103)**。前端 `renderList`(L615-626)含拼音匹配;后端 `listClips`(L249-256)只做子串匹配、**无拼音**。搜索框输入走前端(命中),URL `?q=sf` 或刷新后 `loadClips` 携带 q(后端)不命中。搜索框平时只调 `renderList`(L477-483)不触发后端,故日常使用一致;仅「刷新/直链」场景行为不同,低危

### S-05 | L2 多步往返(启动→剪贴板监听) | 深度 ★缠绕点4
- 操作链:登录 → 刷新页面 → boot 恢复会话(无需重登)→ 外部复制「一段话」→ clipboardchange 触发 → 自动弹存入窗并填入 → 关闭弹窗 → 再复制另一段 → 再次弹窗
- 预期:会话不丢;每次外部复制弹窗一次;弹窗不重复叠加
- 覆盖 C-ID:F-08, F-09, C-03, E-03
- 结果:**通**。boot L1495-1504 显式 token 恢复;监听器仅 boot 绑一次(L1466-1493,无重复注册);`if ($(".mask")) return`(L1476)防覆盖;`openPasteModal` 内 `if ($(".paste-modal")) return`(L1003)防重复弹。恢复失败路径:catch 删 LS 回选用户页 ✓

### S-06 | L4 富文本生命周期 | 深度 ★缠绕点7
- 操作链:从 Word 复制带格式文本 → 自动弹窗 → 内部读 `text/html` 入 `pendingHtml` → 存入 → 卡片出现 🅡 → 点 🅡 → 粘贴到 Word 保留格式 → 另存一条纯文本 → 卡片无 🅡
