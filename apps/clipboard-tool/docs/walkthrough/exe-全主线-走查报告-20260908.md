## 四、分级走查（关键链证据 + 子代理疑点复核）

### 深度链：捕获→去重→存入（S-01/04）
- 外部复制 → WM → `ClipboardWatcher.WndProc:63` 采样 `IsOwnedByThisProcess`，非本进程 → `_pendingExternal=true` → 100ms 防抖 → `ClipboardChanged` → `TryAutoPrompt:123`
- `TryAutoPrompt` 先读剪贴板（文本或 `IsImageOnlyClipboard`），再 `TryTakeClipboardSeq:115`（**序列号去重**）→ `OpenPasteDialog:139` 内 **`FindDuplicate` 预查**（:153）：已有 → 直接开编辑窗(dup)，不重复建卡
- **复核子代理疑点「FindDuplicate 未在 Create 调用」**：非缺陷——Web 语义也是"捕获后存卡窗内检测"，`Create` 本身不查重（去重职责在弹窗预查/输入级兜底），避免自动捕获时静默合并用户的显式新复制
- **复核「自家复制误捕获」**：非缺陷——本程序 SetText/SetImage 后 `MarkSelfWriteAndBump`（MainWindow:400-407）记 `_lastHandledSeq`；自家写入触发的 WM 采样=owned（不置 pending），即使被 debounce 捕获，`TryTakeClipboardSeq` 命中同 seq → return。**双层守卫（watcher pending + MainWindow seq）收敛**

### 深度链：前台语义 + 托盘恢复（S-16）
- OnDeactivated/Minimized → `Paused=true`（:452/485）→ watcher tick 若 Paused 则 `_pendingExternal=false` 丢弃（ClipboardWatcher:41，注释"唤醒后由激活路径兜底"）
- OnActivated → `Paused=false` + 200ms `_activationTimer`（:427-448）→ `PromptFromActivation` → seq 去重弹
- **复核「托盘恢复依赖激活」**：`ShowMainFromTray:586` 显式 `Show()+Activate()+ForceForeground()`，`Activate()` 必触发 OnActivated → Paused 恢复可靠；不依赖隐式激活
- **复核「激活弹窗闪没竞态」**：200ms 延迟 + ModalHost `GuardWindow(450ms)` + `_armed` 防开瞬间误关（ModalHost:163/176）——AGENTS 基线已修（v0.6.x 双回归），结构稳健

### 深度链：WebDAV 同步（S-08/09）
- 手动/定时双入口都经 `Task.Run(SyncEngine.RunSync)`（SyncController:55/66）
- 墓碑 90d TTL + MergeSnapshots 裁决（SyncEngine:32/68-73, WebDavSync:84）
- 单删复活回归：`ClipService.Delete:251` 跨活跃+归档删并**无条件记墓碑**（v0.7.2 修复）→ `finally InFlight.Remove`（:117）
- **复核「下载 dialog owner」**：`dlg.ShowDialog(this)` 位于 MainWindow 的 lambda（`card.DownloadRequested +=`），`this`=MainWindow(Window)，**签名合法、owner 正确**——子代理误判
- **复核「RollToArchive Archived 未置位」**：非缺陷——归档语义=**文件位置**（活跃在 clips.json、归档在 archive.json），`Archived` 字段 `[JsonIgnore]` 不落盘仅内存瞬用（SyncEngine:65）；溢出项物理移入 archive.json 即已归档，读回按归档列表呈现

### 快速链确认（存在即过）：S-02/03/05/07/10-19 各入口在 MainWindow.MakeCard:222-275 全部接线，Search/RefreshWall:194-218 覆盖排序过滤空态，BatchOps/TagBarOps/DataDialog/JsonDialog 事件齐备，selftest 全绿

## 七、走查验证的良好点（程序扎实）
- 捕获→去重→存入**双层守卫收敛**（watcher pending + MainWindow 序列号），防重复弹窗/防自家误捕获，非补丁而是双点收敛
- 同步墓碑 90d + 删卡无条件记墓碑，删后同步不复活有回归用例（SelfTest），机制完整
- 前台语义 Paused + 托盘/二次唤起显式 Activate，恢复可靠
- 归档/活跃以文件位置区分（JsonIgnore Archived），无状态漂移
- 原子写 tmp+rename、读坏文件容错、文件 10MB/黑名单/防穿越，边界覆盖全
- 双版本规则差分门禁（41 fixtures）+ selftest 全绿，规则一致性机器把关
