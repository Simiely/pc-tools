## 三、分级走查（逐链 Read 证据）

### S-01 图片卡出现 + hover 弹预览 —— ✅ 通
- 入口 `SetClip:120 BuildImageBody` → 图解码失败降级文件卡（:122）
- `_imageBytes` 在 :358 缓存（hover 预览/复制复用），非 null 才可预览
- hover `ImgWrap_MouseEnter:519` → 260ms 延迟 → `OpenImagePreview`；防重 :567（已开则 return）
- 关键：**浮层只在卡片图片区 MouseEnter 触发**（wrap 上挂），文本/文件/链接卡无此挂载 → 跨类型安全

### S-02 cap 黑字白描边去圆角底 —— ✅ 通（本轮核心）
- `OpenImagePreview:627-653`：单 TextBlock，`Foreground=Black`，`Effect=DropShadowEffect{White,BlurRadius=1,ShadowDepth=0,Opacity=1}`
- 单元素把字形渲一圈细白边；**结构上只有 1 个 TextBlock → 不可能重复**（切断历史 StackPanel 横排根因）
- `IsHitTestVisible=false` → 点击穿透到 bg 触发复制
- 无任何 Border 半透黑圆角底残留（grep 孤儿引用 NONE）

### S-03 缩放不上下跳 —— ✅ 通（本轮核心）
- 开浮层 :691-699 用卡片中心相对屏工作区一次性定 `_previewAnchorAbove`（roomBelow<roomAbove→上方）
- `RepositionPreview:725-737` 垂直**只按该边**：上方→`Max(wa.Top+8, cardY-bh-4)`；下方→`Min(wa.Bottom-bh-8, cardY+h+4)` 再兜底——**绝不 if/else 翻转换边**
- 缩放触发 `ApplyPreviewScale` 同步 box/img/cap + HorizontalOffset±0.001 重新 placement（box 显式宽高 → Popup 视窗跟）
- 验证：build 前旧代码有 `(topAbove>=wa.Top+8)?topAbove:topBelow` 翻转分支（已删），现无翻转 → 结构性消灭上下跳

### S-04 300% 高图边缘钳制 —— ✅ 通（已知取舍）
- 上方锚定 300% 高图：`top=Max(wa.Top+8,...)` 顶钉屏顶不飞；底可能超出屏底（无 ScrollViewer 不可平移）——**既有设计取舍**（去 ScrollViewer 根治白边），非本轮引入；zoom 上限 300% + 开时视口钳制已缓冲

### S-05 点击预览图复制 —— ✅ 通（本轮新增）
- `bg.MouseLeftButtonUp:663-670`：先 `CloseImagePreview()`（清 timer/popup 引用）再 `Copy(_clip,x,y)`，`e.Handled=true`
- Popup 独立窗格 → 点击不透传卡片单击（卡片单击复制 / 双击编辑不受影响）
- `Copy:823-837` 图片卡 → `CopyImageRequested` → MainWindow `CopyImageToClipboard:363-382`（FileStore 重读 → ClipboardHelper.SetImage → toast）
- `_clip` 非 null 守卫 + batch 模式不弹预览 → 无越界复制

### S-06/07 停留态 + 关后重开 —— ✅ 通
- 停留：bg.MouseEnter 取消待关(:672-677)；MouseLeave 220ms 延迟(:678-690)，期间进入浮层取消
- 关：`CloseImagePreview:772-790` 停两个 timer、`_inFloater=false`、字段置 null、popup Child 置 null 并 wheel 退订
- 重开：OpenImagePreview 开头 `_imgPreviewScale=1.0` 重置 + `_previewAnchorAbove` 重新定 → 无旧态残留

### S-08/09 窄图 / 超大图 —— ✅ 通
- cap MaxWidth=`Max(40, dispW-8)`(:653) + TextTrimming 省略号 → 窄图截断不溢出
- 超大图开时 fitScale<1 初始缩小(:588-596)

### S-10 批量守卫 / S-11 跨类型 —— ✅ 通
- ImgWrap_MouseEnter:521 `if(BatchMode) return` → 批量不弹预览
- mouseenter 仅挂图片 wrap → 其他类型卡无预览入口

## 七、结论三问
1. **链路逻辑通顺吗？** ✅ 通。hover→260ms→popup→缩放→点击复制→关，每跳都有真实入口与守卫。
2. **是补丁叠补丁吗？** ❌ 不是。重复/白边/跳动三类历史问题均由"单元素/显式尺寸/固定锚定"结构根除，无单点堆叠。
3. **会无法操作/出 bug 吗？** 能操作。唯一 UX 提醒 = 点击必复制（W-01），属需求本身，非缺陷。
