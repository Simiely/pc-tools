## 三、深度走查结果

### S-R1（自动弹出场景）—— 🔴 断链

逐行模拟（关键证据）：

```
1. 用户复制 Word 富文本 → 剪贴板含 text/html + text/plain
2. clipboardchange 触发（app.js:1848）→ readText 成功，文本 t 有值
3. openPasteModal(true)（app.js:1865）
4. autoFillPasteModal（app.js:1384）：
     pendingHtml = ""
     read() ← 预览 iframe 无 clipboard-read 权限（Permissions Policy 未授权）
              → catch(() => []) → items = []          ★ 断点 1
     → pendingHtml 保持空
     readText 有文本 → ta.value = t → return
5. 用户点存入 → savePasteContent（app.js:1348）：
     const html = pendingHtml || "";   → ""           ★ 断点 2
     api POST { content, ...(html ? {html} : {}) } → 不传 html
     → 后端存【纯文本条目】
6. 卡片渲染（makeRichSplit）：c.html 不存在 → 右栏为纯文本（c.content）
7. 点右栏 → copyRich("", content) → 剪贴板只有 text/plain
8. 粘贴 → 普通文本 ✗✗✗
```

**根因（权威依据 web.dev/Async Clipboard）**：
- `clipboard.read()` 读取剪贴板**需要 clipboard-read 权限**，iframe 内需父页面 `allow="clipboard-read"`，WorkBuddy 预览 iframe 未授权 → read() 被 Permissions Policy 拦截返回空
- 自动弹出场景的 html 捕获**唯一依赖 read()** → 权限失败则 html 全程丢失
- 手动粘贴（S-R2）走 paste 事件 `getData("text/html")`（不需 read 权限）→ 已修，可靠 ✅

### S-R2（手动粘贴场景）—— ✅ 通

paste 事件捕获 html（app.js:1228 重写后）→ pendingHtml 有值 → 徽章显示「✦ 将存为:格式文本」→ 存入带 html → 复制带格式。

## 四、问题清单

| 编号 | 级别 | 问题 | 位置 | 风险分 L×I |
|---|---|---|---|---|
| R-1 | 🔴 真缺陷（环境限制） | 自动弹出场景 html 捕获依赖 clipboard.read()，预览 iframe 权限未授权 → pendingHtml 空 → 存成纯文本，后续复制必然无格式 | autoFillPasteModal read() catch → []；savePasteContent `html = pendingHtml || ""` | 5×5=25 |
| R-2 | 🟡 UX | 自动场景格式丢失无任何提示，用户不知道已存成纯文本（徽章只显示「文本」） | autoFillPasteModal 无 read 失败提示 | 3×3=9 |

## 五、修复方案（基于权威）

**预览 iframe 内自动场景无法绕过 read 权限（浏览器安全模型）**，可行路径：
1. read() 失败且 readText 有文本时 → **提示用户「剪贴板含格式但预览面板无法读取，请 Ctrl+V 粘贴以保留格式」**（引导走 S-R2 可靠路径）
2. 独立浏览器：read() 首次弹权限提示，授权后自动场景正常
3. 手动粘贴路径已可靠（S-R2 ✅）

## 七、根因终审（2026-08-16 10:36 实测闭环）

**隔离诊断页实测（diag.html，非 iframe，API 全可用）**：
- paste 事件取到 Word 原始 mso HTML 43408 字节（含 `<style>`）
- execCommand 复制 → 读回 4963 字节（`<style>` 块被浏览器剥，但 **inline style 保留**，如 `font-size:24pt; color:rgb(15,71,97)`）
- **用户粘贴到 Word 时，Word 默认「合并格式」→ 显示无格式；选「保留源格式」→ 格式完整还原 ✅**

**终审结论**：
- 🔴 R-1/R-2 降级为 ⚪ 极低：复制/存入链路**功能正常**，「无格式」是 **Word 粘贴默认「合并格式」行为**（非代码缺陷），选「保留源格式」即正常
- 环境非 iframe、Clipboard API / execCommand / paste 全可用（实测证据）
- 保留改进（非缺陷修复）：paste 事件捕获 html（存入更可靠）、read 权限失败提示、CSS 类名 `.rich-pv`→`.re-pv` 消除显示污染、诊断页 diag.html（排障工具）
