# docs/archive

一次性分析报告、历史方案与走查/验证脚本的归档区(对应发布规范中"剔除开发中间产物"的要求)。

## 归档规则

- **何时归档**:单次分析/走查/验证任务产出、已过时或被替代的开发脚本、阶段性架构评估——任务结论落入 CHANGELOG/DEVELOPMENT/AGENTS 后即归档至此。
- **不归档**:仍在维护的规范(AGENTS.md、发布规范.md、DEVELOPMENT.md、docs/walkthrough 中仍被引用的走查报告)。
- **移动方式**:使用 `git mv` 保留历史;跨期内容日期前缀可选(如 `2026-09-03-verify-paste.ps1`)。
- **危险脚本入档前必须无害化**:如含删除用户数据类命令,先改为备份/确认语义(见 verify-paste.ps1 案例:Remove-Item "$pub\data" -Recurse → Move-Item 到 %TEMP% 备份)。
