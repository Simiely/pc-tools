# clipboard-tool 功能清单与操作模拟方案

> 版本基线：本地工作副本（v0.1.0 ~ v0.3.0 + 用户选择页编辑模式），服务 `http://127.0.0.1:8130`
> 用途：**功能验收 / 回归测试 / 找 bug 的剧本**。三个梯队（普通 5 / 复杂 5 / 乱点横跳 10）共 20 个方案，覆盖全部功能。

---

## 第一部分：功能清单（当前代码全量盘点）

| # | 功能 | 入口 |
|---|---|---|
| A1 | 用户选择页（未登录的卡片列表） | 打开页面 / 切换用户 |

## 第二部分：5 个普通方案（正常使用路径）

### 方案 1：新用户首次使用全流程
1. 打开 `http://127.0.0.1:8130` → 看到用户选择页（A1）
2. 点「＋ 新建用户」→ 输入昵称「小明」→ 密码留空 → 「创建并进入」（A2/A3）
3. 顶部「存入内容」→ 粘贴一段文本「测试内容」→ 自动识别为文本 → 点「存入」（B1/B2）
4. 列表出现条目 → 点卡片 → 复制成功 + 提示「已复制」→ 复制计数变 1（B6）
5. 点「退出」→ 回到用户选择页（A5）
6. 再点「小明」卡片 → 直接进入（无密码零摩擦，A3）

### 方案 2：链接收藏与星标置顶
1. 新建用户「小红」（带密码 `abc123`）（A2）
2. 存一个链接 `https://example.com/page?utm_source=news&id=5`（B1）
3. 确认列表里 URL 已被清理为 `https://example.com/page?id=5`（F9）
4. 点卡片「打开」→ 新标签页打开（B2 链接操作）
5. 点卡片右上角「☆」→ 变「★」，卡片出现琥珀色描边（C1 星标置顶）
6. 再存几条普通内容 → 星标条目始终排第一（C1）

### 方案 3：文件与图片管理
1. 用户选择页 → 进入任意用户（A3）
2. 存入弹窗 → 拖一个 `.png` 图片进去 → 「存入」（E1/B1）
3. 点图片卡片 → 图片复制到系统剪贴板 + 提示「图片已复制，可直接粘贴」（E3）
4. 点「下载」→ 浏览器下载该文件（E2）
5. 尝试上传一个 `.exe` → 被拒，提示「不支持上传该类型」（E5）

### 方案 4：标签与搜索
1. 存入多条内容，分别打标签：「工作」「常用」「身份证明」（D1/B2）
2. 搜索框输入 `身份` → 命中「身份证明」那条（C2）
3. 搜索框输入 `sf`（拼音首字母）→ 同样命中「身份证明」（C3）
4. 点标签条「工作」→ 列表只显示该标签（C4）
5. 点类型 Tab「链接」→ 只显示链接类（C5）
6. 设置 → 标签管理 → 把「工作」改名为「职场」→ 返回列表确认标签已变（D2）

### 方案 5：数据备份（导出 → 导入）
1. 进入用户，存几条内容（B2）
2. 设置 → 本地备份 → 「导出全部」→ 浏览器下载 `clipboard-名字-日期.json`（F3）
3. 删掉全部条目（B5 全部清空）
4. 设置 → 本地备份 → 「导入合并」→ 选刚才的文件 → 提示「新增 N 条」（F4）
5. 确认条目全部恢复（F4 合并语义）

## 第三部分：5 个复杂方案（多步骤组合）

### 方案 6：完整编辑生命周期（含过期与归档）
1. 新建用户，存一条文本（B2）
2. 双击该条目 → 编辑弹窗 → 改标题 + 加标签 + 设过期「1 小时后」（B3/D1）
3. 卡片出现「1 小时后过期」徽标
4. 连续存 510 条内容（可脚本批量）→ 触发滚动归档（F1）
5. 确认活跃区只剩 500 条，归档 10+ 条（F1）
6. 勾选工具栏「含归档」→ 归档条目出现，带「归档」徽标且无编辑/删除按钮（F2）
7. 搜索含归档 → 能搜到归档内容（C2+F2）
8. 等待或手动验证过期条目被 60s 清扫移除（G3）

### 方案 7：多用户数据隔离 + 密码安全
1. 建用户 A（无密码）和用户 B（密码 `passB`）（A2）
2. A 存「机密A」，B 存「机密B」（B2）
3. 切到 A → 搜「机密B」→ 搜不到（数据隔离，C2）
4. 用 A 的 token 请求 B 的文件 → 404（归属校验，E2）
5. B 输错密码 8 次 → 被限流提示「尝试过于频繁」（A8）
6. B 正确密码登录 → 成功（限流只锁失败，不锁成功）
7. 用户选择页 → 点右上角「编辑」→ B 卡片出现 ✕ → 点 ✕ → 确认 → 弹出密码验证 → 输对 → 删除成功（A7）
8. 用户列表刷新，B 消失（A7）

### 方案 8：WebDAV 完整生命周期
1. 先起 mock WebDAV（`node scripts/mock-webdav.mjs 8180`）
2. 用户选择页进入用户，存 3 条内容（B2）
3. 设置 → WebDAV → 填 `http://127.0.0.1:8180/dav/` + admin/admin123 → 「测试保存」（F5）
4. 填错误密码再测 → 401 提示认证失败 → 不保存（F5）
5. 重新填对 → 「一键同步」→ 远端生成快照 `clipboard-<uid>.json`（F6）
6. 删除 1 条 → 再同步 → 远端快照该条消失 + 墓碑记录（F6 墓碑机制）
7. 另一设备（或清空本地）→ 一键同步 → 从远端拉回（F6）
8. 勾选「同步文件实体」→ 上传一个文件 → 同步 → 远端 files/ 有实体（F8）
9. 删除本地实体 → 再同步 → 远端拉回（F8）

### 方案 9：JSON 工具链
1. 存一条文本内容 `{"name":"test","list":[1,2,3]}`（B2）
2. 卡片右上角出现 `{}` 按钮（F10 检测）
3. 点 `{}` → 弹窗显示美化后的 JSON（缩进对齐）（F10）
4. 点「复制美化结果」→ 剪贴板拿到美化版（F10）
5. 点「覆盖保存」→ 条目内容变成美化版 → 列表刷新（F10）
6. 再存一条非 JSON 文本 → 确认无 `{}` 按钮（F10 只对 JSON）
7. 存一条超大文本（>100KB）→ 确认不触发格式化（防卡顿）

### 方案 10：会话安全与持久化
1. 用户 A 登录，拿到 token（A3）
2. 再开一个浏览器窗口（模拟第二设备）登录同用户 A，拿第二个 token（A3）
3. 第一窗口改密码（A6）→ 第二窗口请求 API → 401（改密销毁其他会话）
4. 第一窗口仍有效（保留当前会话）（A6）
5. **重启服务**（杀进程再起）→ 第一窗口刷新 → 仍登录（会话落盘，A4）
6. 点「退出」→ token 销毁 → 刷新要求重登（A5）
7. 删除该用户 → 旧 token 立即失效（A7 后端联动）

## 第四部分：10 个乱点 / 反复横跳方案（找 bug 剧本）

### 方案 11：搜索词反复横跳
1. 输入「身份」→ 出结果
2. 立刻改成「sf」→ 出拼音结果
3. 清空 → 全列表
4. 输入「不存在的词xyz」→ 「没有匹配的内容」提示
5. 快速输入「a」「ab」「abc」「b」各停 50ms → 验证防抖不崩、无重复列表
6. 搜索 + 类型 Tab 组合：「身份」+ 点「链接」→ 结果为空提示正确

### 方案 12：存入弹窗乱操作
1. 点顶部「存入内容」→ 弹窗开（B1）
2. 不输入直接点「存入」→ 提示「先粘贴内容或选择文件」
3. 粘贴内容后点「高级」→ 输入别名 → 不保存直接关弹窗
4. 重开弹窗 → 确认别名未残留（弹窗状态干净）
5. 弹窗开着时，从外部复制内容 → 检测到 clipboardchange → **弹窗已开不重复弹**（B1 防重）
6. 关闭弹窗后立刻复制 → 弹窗自动再开（B1）
7. 弹窗开着时点「关闭」再快速点「存入」→ 无报错（防连点锁）

### 方案 13：星标反复横跳
1. 存 3 条内容 A/B/C（B2）
2. A 点星标 → 置顶排第一
3. A 取消星标 → 回原排序
4. B 置顶 → A 取消 → 快速连点 A 的星标 5 次 → 验证最终状态一致（防抖/幂等）
5. 星标后刷新页面 → 置顶状态保留（持久化）
6. 置顶 + 复制次数混合：A 星标 + 复制 3 次 vs B 无星标 + 复制 10 次 → A 仍在前（C1 优先级正确）

### 方案 14：编辑弹窗反复开合
1. 双击卡片 A → 编辑弹窗开
2. 改标题 → 不点保存 → 点遮罩关闭（丢弃修改）
3. 双击卡片 A → 确认标题未变（丢弃生效）
4. 改内容 + 标签 → 保存 → 列表刷新（B3）
5. 编辑弹窗开着时再双击另一卡片 → 验证弹窗被替换而非叠加（弹窗互斥）
6. 保存后立刻再编辑 → 无残留状态（U-7 防双界面）

### 方案 15：删除确认反复
1. 点卡片「删除」→ 确认框弹出
2. 点「取消」→ 条目还在
3. 再点「删除」→ 确认框 → 点遮罩关闭 → 条目还在
4. 再点「删除」→ 按 Esc → 条目还在
5. 再点「删除」→ 点「确认」→ 条目删除 + 「已删除」提示（B4）
6. 对最后一条删除 → 出现「还没有内容」空态
7. 空态下再点删除任何卡片 → 无报错

### 方案 16：编辑模式反复进出
1. 用户选择页 → 点「编辑」→ 所有卡片出现 ✕（A7）
2. 点某卡片 ✕ → **不应进入用户**，应弹确认框（防误进）
3. 点「取消」→ 仍在编辑模式
4. 点「完成」→ ✕ 全部收起
5. 再点「编辑」→ ✕ 重现 → 再点「完成」（反复 3 次，验证状态干净）
6. 编辑模式开着时直接点卡片 → 进入用户（可接受：点击卡片本体）
7. 有密码用户在编辑模式删 → 密码验证弹窗 → 取消 → 用户还在

### 方案 17：列数与过滤横跳
1. 列数切「2 列」→ 列表两列显示（C6）
2. 切「1 列」「3 列」「4 列」「自适应」来回快速切换 → 布局不崩、滚动不丢（C6）
3. 刷新页面 → 列数偏好保留（C6 记忆）
4. 「自适应」+ 搜索 + 标签 + 类型 Tab 全组合乱切 → 列表始终正确过滤（C2/C4/C5）
5. 列数切换时点开编辑弹窗 → 弹窗正常、列表重排不闪（C6+B3）

### 方案 18：过期设置反复改
1. 存一条内容 → 编辑 → 过期设「1 小时」（B3）
2. 再编辑 → 改「永久」→ 确认徽标消失（B3）
3. 再编辑 → 改「30 天」→ 徽标显示「30 天后过期」（B3）
4. 反复在 1h/1d/7d/30d/永久 间切换 5 次 → 最终值与选择一致（B3）
5. 存一条「1 小时后过期」→ 等清扫或缩短时间 → 条目消失（G3 过期清扫）
6. 过期条目被归档后 → 含归档搜索 → 过期条目不显示（F2+过期过滤）

### 方案 19：标签管理乱操作
1. 存两条，标签分别 `x` 和 `x,y`（D1）
2. 设置 → 标签管理 → 把 `x` 改名为 `z` → 两条都变 `z`（D2）
3. 把 `z` 再改回 `x` → 合并去重：`x,y` 不出现重复 `x`（D2）
4. 删除标签 `y` → 仅移除标签，条目还在（D2）
5. 删除不存在的标签 → 「标签不存在」提示（D2）
6. 改名输入空值 → 「标签名无效」（D2）
7. 改名后返回列表 → 标签条、卡片标签、搜索全部同步（D2+C4+C2）

### 方案 20：导入/导出与同步交替横跳
1. 导出全部 → 得文件（F3）
2. 导入同一文件 → 全部「跳过」（同 id 重复）（F4）
3. 修改文件里某条 updatedAt +1 → 导入 → 「更新 1 条」（F4）
4. 追加一条新 id → 导入 → 「新增 1 条」（F4）
5. 导入格式错误的文件（如纯文本）→ 提示「不是剪贴板备份文件」（F4）
6. WebDAV 已配置时，先一键同步再导入导出 → 数据一致不冲突（F6/F3/F4）
7. 导出 → 删全部 → 导入 → 恢复（F4 完整闭环）
8. 导入超大文件（>1000 条）→ 提示「导入条目过多」或正常滚动归档（F4+F1）
