位置与间距调整说明（相对现有界面）

  • 容器加宽：720px → 960px 居中（新拟态浮雕需要呼吸感，卡片网格更舒展）
  • 类型 Tab 改分段控件：独立描边胶囊 → 凹陷轨道 + 凸起选中项（新拟态标志性交互）
  • 搜索框改胶囊内嵌：描边方框 → 凹陷 pill + 放大镜图标，语义=「可输入区域」
  • 卡片间距加大：10px → 16px，hover 抬升 3px + 阴影加深（浮雕浮起感）
  • 顶栏改整条浮雕面板：按钮从描边 ghost 改为凸起小按钮，按压回弹
  • 存入入口：虚线框 → 凸起条 + 副文字提示，按压凹陷
  • 主强调色切换：#ff9292 粉 → #7f9dff 蓝紫（风格手册新拟态标准色）
  • 置顶卡片：整卡琥珀描边 → 仅保留琥珀双阴影光晕，弱化视觉噪音
  • 无边框原则：全界面取消 1px 描边，轮廓全部由双阴影定义
