# 目录地图 · Directory Map

本地目录浏览/管理工具：把一个深层级文件夹，生成一张**可浏览、可编辑的表格页面**（像电子表格一样管理你的目录）。

## 特性

- **层级/扁平视图** + 搜索 + 点列头排序 + 折叠展开
- **电子表格式编辑**：动态增删列、改列名、每格可编辑、标签徽章
- **列管理**：拖宽列宽、拖列头换位置（名称/序号/标签锁定）、列收起成书签
- **网址自动可点**：单元格/备注里的 `http(s)://` 链接一键打开
- **数据随文件走**：备注/标签/列值自动写回 `data.js`，换电脑不丢
- **零依赖**：Python 标准库 + 原生 HTML/JS，无任何第三方包
- 深海青灰 HMI 配色，深浅主题可切，滚动条适配

## 文件构成

| 文件 | 作用 |
|---|---|
| `scan_map.py` | 生成器：扫描目录 → 读取模板 → 输出 `HTML + data.js`，重跑自动合并旧数据 |
| `dirmap_template.html` | 前端模板（单文件，含全部 UI/JS） |
| `serve.py` | 本地服务：静态文件 + 接口（打开文件夹/保存数据/刷新目录） |
| `check_js.py` | 自检工具：`node --check` 校验 HTML 内嵌 JS 语法 |

## 安装

- Python 3（任意 3.x 版本，标准库即可，零第三方依赖）
- 生成后使用不需要 Python（双击 HTML 即可，数据已内嵌）

## 快速开始

```bash
# 1. 生成某个目录的地图
python scan_map.py D:\work\251208           # 输出到目标目录
python scan_map.py D:\work\251208 D:\out    # 或指定输出目录

# 2. 服务模式（推荐：可刷新目录/打开文件夹/数据写回 data.js）
python serve.py                              # 放在目标目录里双击/运行，自动识别
python serve.py 8766 D:\work\251208          # 指定端口和目录

# 3. 或者：直接双击生成的「<目录名>-目录地图.html」即可浏览
#    （双击模式：编辑内容存浏览器本地）
```

## 部署（发给别人用）

把 `<目录名>-目录地图.html` + `<目录名>-目录地图.data.js` + `serve.py` 三个文件放进目标目录，双击 `serve.py` 即可。
