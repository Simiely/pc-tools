# CHANGELOG.md

本项目所有版本变更记录。格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

- 准备开源到 GitHub（单项目规范四件套文档建立）

## [1.4.0] - 2026-08-13

### 修复
- 横向滚动条根治：`html,body` / `main` / `table` 三层 `max-width` 硬限制（依据：列宽总和 > 容器必溢出）
- 拖动列宽有上限（最多吃光弹性列可压缩空间），总宽锁定不超屏

### 重构
- 持久化收敛：`saveNotes()` 成为唯一保存入口（notes/columns/colW/hidden 一次写入）
- `rowHtml` 拆分 `nameCellHtml/tagCellHtml/customCellHtml`（函数 <20 行）
- 新增 `check_js.py`：`node --check` 校验 HTML 内嵌 JS 语法（防止重复声明类错误）

## [1.3.0] - 2026-08-10

### 新增
- 宽度分配机制：左右固定区（操作/序号/名称/标签 + 大小/修改时间）+ 中间自定义列弹性均分，总宽 = 浏览器宽
- 收起列书签（表头上方横排，点击展开）
- 深海青灰配色方案（`#14181D` 系），滚动条深色适配

### 变更
- 名称列最小/默认 350px；操作列 90px；序号 50px；修改时间 140px（最右列不可拖宽）
- 标签列位置锁定、左对齐、宽度可调；操作列按钮左对齐
- 去除类型/备注列

## [1.2.0] - 2026-08-10

### 新增
- 列宽拖拽（修复拖拽手柄缺失、`draggable` 未设置导致的无法拖动）
- 列交换（拖列头换位，名称/序号/标签锁定）
- 行号列（#，默认排序序号，不做排序操作）
- 自定义列/备注中的网址自动可点击（↗ 按钮 + 链接化）

### 修复
- 拖动结束误触发排序（suppressClick 抑制）

## [1.1.0] - 2026-08-10

### 新增
- 动态列管理：添加列 / 双击改名 / 删列（列配置持久化到 data.js）
- 标签功能：行级彩色徽章，可增删
- 点列头排序（自动切扁平视图）
- 自制模态框替代原生 `prompt/confirm`（预览面板 iframe 禁用原生弹窗）

### 修复
- 整体检查修复 6 个问题：添加列不显示、改列名后列消失、空行加标签报错、删列残留、colspan、URL 按钮不实时更新

## [1.0.0] - 2026-08-10

### 新增
- 目录地图初版：层级表格 + 备注编辑 + 服务模式（serve.py 落盘 notes.json/data.js）
- 通用化生成器（scan_map.py）、一键启动（start_map.bat）
